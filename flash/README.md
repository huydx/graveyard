# Flash Quiz

A web app that turns your notes from multiple sources (Notion, URLs, or pasted text) into a **daily quiz** so you're reminded of what you noted. No typing or speaking—answer with **flash cards** (flip and rate) or **multiple choice**.

## Features

- **Sources**: Add Notion links, any public URL, or paste notes. The system can fetch content from URLs and summarize it. With an **OpenAI API key**, the main page is summarized by LLM (default model: `gpt-4o-mini`); you can also **follow links** (0–5) to fetch and summarize linked pages.
- **Concepts**: Content is split into concepts (by headings/paragraphs). You can run "Extract concepts" after pasting or fetching.
- **Quiz**: Each concept generates a flashcard and a multiple-choice question. "Today's quiz" shows a random set; you rate each item (correct/incorrect) without typing.

## Tech stack

- **Backend**: Go (Chi router), SQLite
- **Frontend**: React (Vite), React Router
- **Database**: SQLite (file in `backend/data/flash.db`)

## Run locally

### Backend

```bash
cd backend
go build -o flash ./cmd/server
./flash
```

Options:

- `-addr=:8080` — listen address (default `:8080`)
- `-data=./data` — directory for SQLite file (default `./data`)

**OpenAI API (optional):** Set `OPENAI_API_KEY` so that when you **Fetch URL**, the backend uses the OpenAI API to summarize the page (and any followed links) instead of a plain excerpt. Default model is `gpt-4o-mini`; override with `OPENAI_SUMMARIZE_MODEL`. On the source detail page, use **Follow links** (0–5) to also fetch and summarize that many outbound links from the page.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). The Vite dev server proxies `/api` to the Go backend at `http://localhost:8080`.

### One-shot (both)

Terminal 1:

```bash
cd backend && ./flash
```

Terminal 2:

```bash
cd frontend && npm install && npm run dev
```

## Usage

1. **Sources** → Add a source: name + optional URL and/or pasted content.
2. If you set a **URL**: open the source and click **Fetch URL** to pull and store the page content. If `OPENAI_API_KEY` is set, the summary is generated by OpenAI (e.g. `gpt-4o-mini`). Optionally set **Follow links** (1–5) to fetch and summarize linked pages too.
3. Click **Extract concepts** to split content into concepts and generate quiz items (flashcard + multiple choice per concept).
4. **Quiz** (or "Start today's quiz" on home): answer the daily set with flash cards (flip, then "Got it" / "Forgot") or multiple choice. Reviews are stored for future use.

## Notion

Notion pages often require login, so public URL fetch may not work for private pages. For those, paste the note content into the source and use **Extract concepts** only. For public Notion pages, you can try **Fetch URL** first.
